07번은 가입 이름/전화번호 저장, 출석 기기 등록·해제, 전화번호 조회·출석 처리, 출석 기록과 접근 권한을 추가합니다. 이메일과 비밀번호는 Supabase Authentication이 관리합니다. 06번 자동결제 스케줄이나 Edge Function 배포 없이도 이번 로그인·출석 기능을 사용할 수 있습니다. 실제 결제에는 기존 안내의 결제 서버 설정이 별도로 필요합니다.

## 이메일 인증 설정

Supabase → Authentication에서 다음을 설정합니다.

1. 이메일 로그인 공급자를 활성화하고 가입 허용과 Confirm email(이메일 확인)을 켭니다. 네이버·카카오·Google 설정은 필요 없습니다.
2. URL Configuration의 Site URL: `https://k2551344-creator.github.io/myweb1/`
3. Redirect URLs에 아래 두 주소를 허용합니다.
   - `https://k2551344-creator.github.io/myweb1/`
   - `https://k2551344-creator.github.io/myweb1/?auth=recovery`
4. SMTP 설정에 실제 이메일 발송 서비스의 호스트·포트·사용자·비밀번호·발신 주소를 등록합니다. 비밀값은 GitHub나 채팅에 올리지 않습니다. Supabase 기본 메일 발송은 테스트용이며 수신자와 발송량 제한이 있어 일반 회원 대상 운영에는 별도 SMTP 설정이 필요합니다.
5. 실제 사용할 이메일로 가입 → 이메일 확인 → 로그인 → 비밀번호 찾기 → 메일 링크 → 새 비밀번호 저장 → 다시 로그인 순서를 점검합니다. 메일 발송 서비스 연결과 실제 수신은 아직 확인하지 않았습니다.

회원 기본정보는 이름·이메일·전화번호 3가지입니다. 여기에 로그인에 사용할 비밀번호를 정합니다. 이름과 전화번호는 내 정보에서 수정하며 이메일은 가입 계정의 주소를 표시합니다. 전화번호 입력은 문자 인증이 아닙니다.

로그인은 같은 브라우저에 저장되고 자동 갱신됩니다. 직접 로그아웃, 브라우저 데이터 삭제, 시크릿 모드 종료, 서버 보안 정책에 따른 만료 시 다시 로그인해야 합니다. 공용 PC에서는 반드시 로그아웃하세요.

공식 안내: [비밀번호와 이메일 인증](https://supabase.com/docs/guides/auth/passwords), [운영용 이메일 발송 설정](https://supabase.com/docs/guides/auth/auth-smtp).

## 센터 태블릿 출석

1. 관리자로 로그인 → 지점 선택 → 관리자 → **출석·기기 설정**.
2. 기기 이름을 적고 **기기 등록 링크 만들기** → 복사.
3. 출석 전용 태블릿의 별도 브라우저에서 링크를 엽니다. 이 브라우저에는 관리자 계정을 로그인해 두지 않습니다. 링크는 회원에게 공유하지 않습니다.
4. 이후 같은 기기에서 `https://k2551344-creator.github.io/myweb1/?kiosk=1`을 열면 출석 화면이 나옵니다.
5. 회원이 뒤 4자리를 입력하면 조회됩니다. 같은 번호가 여러 명이면 본인을 선택합니다. 이름 확인 후 **출석하기**를 누르거나 **5초**를 기다리면 출석됩니다. 이름이 같아 구분되지 않으면 데스크에 문의하도록 안내합니다.
6. 완료 후 5초가 지나면 다음 회원 화면으로 돌아갑니다. 선택하지 않고 60초가 지나면 표시된 이름도 지웁니다.
7. 태블릿 분실·교체 시 관리자 화면에서 해당 기기를 사용 해제합니다. 기존 등록 링크도 즉시 사용할 수 없게 됩니다.

전화번호 뒤 4자리는 출석 조회용이며 회원 계정 로그인이나 결제 인증에는 사용하지 않습니다. 등록된 기기만 이름과 출석용 선택값을 받으며 전체 전화번호·이메일·결제 내역은 받지 않습니다. 직원이 관리하는 센터 내부에서 사용하세요. 같은 이름과 같은 뒤 4자리까지 겹치는 경우 자동으로 식별할 수 없습니다.

이용 가능한 지점·회원권 유효기간·결제 상태·주간 횟수를 서버에서 다시 확인합니다. 한국 시간 기준 월요일부터 한 주, 하루 한 번 출석합니다. 구독 해지를 신청했어도 결제한 이용기간이 남아 있으면 출석 가능합니다. 기존 subscriptions 회원권도 지원하며 기존 attendance 성공 기록은 중복·주간 횟수 계산에 포함합니다. 새 출석 내역은 gym_attendance에 저장되고 관리자 최근 출석에 표시됩니다.
