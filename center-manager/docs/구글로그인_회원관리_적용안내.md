## 관리자 사용법

### 회원 직접 추가

관리자 → 지점 선택 → **전체 회원·수강증** → **현재 지점에 회원 직접 추가**. 이름·회원이 사용할 Google 계정 이메일·전화번호를 입력합니다. 같은 지점의 같은 이메일은 중복 등록하지 않습니다.

Google 가입 전에도 센터 회원으로 관리하고 수강증을 부여하거나 출석할 수 있습니다. 같은 이메일의 인증된 계정이 이미 있으면 연결하고, 나중에 Google로 가입하면 로그인 시 연결합니다. 전화번호나 이름만 같다는 이유로 다른 계정에 연결하지 않습니다. 잘못된 이메일을 입력하면 의도한 회원에게 연결되지 않으므로 반드시 확인하세요. 등록 버튼이 Google 계정이나 임시 비밀번호를 만드는 것은 아닙니다.

회원 직접 등록과 온라인 계정 연결은 지점별로 저장합니다. 온라인 가입 회원은 처음 내 정보 화면을 열 때 선택한 지점에 등록됩니다. 기존 구매 회원 및 기존 center_members 데이터도 목록에 포함합니다. 센터에 아직 등록하거나 구매하지 않은 단순 인증 계정은 전체 회원 목록에 포함하지 않습니다.

### 수강증 부여

회원 상세 → **수강증 부여** → 해당 지점 상품, 이용 시작일, 마지막 이용일, 주간 횟수(0 = 제한 없음), 사유 입력. 마지막 이용일 밤까지 사용할 수 있습니다.

이 기능은 센터에서 이용권을 직접 부여하는 기능입니다. 카드 결제나 자동결제 계약을 만들지 않습니다. 수납을 했다는 결제 기록이나 환불 기록도 만들지 않습니다. 기존 유효 회원권과 별도로 보관하며 구매 회원권 및 센터 부여 수강증은 회원의 내 정보에 함께 표시됩니다.

### 구독 중지

- **다음 자동결제 해지**: 다음 결제를 중단하고 이미 결제한 기간의 이용은 유지합니다.
- **즉시 이용 중지**: 해당 회원권의 출석과 다음 자동결제를 중단합니다.
- **이용 재개**: 원래 기간 안에서 이용을 재개합니다. 자동결제는 다시 시작하지 않습니다.

이미 결제된 금액의 환불, 기간 연장, 락카 반납·재배정은 포함되지 않습니다. 결제 처리 중이면 결과가 확정된 뒤 변경해야 합니다. 다른 유효 수강증이 남아 있으면 그 수강증으로 출석할 수 있습니다. 부여·정지·해지·재개에는 관리자와 사유가 서버 감사기록에 남습니다.

### 전체 회원 조회와 다운로드

**관리 지점 전체**를 선택하면 본인이 소유자/매니저 권한을 가진 모든 지점의 회원을 조회합니다. 이름·이메일·전화번호 검색과 50건 단위 페이지 이동을 지원합니다. 같은 사람이 여러 지점에 등록되면 지점별 기록으로 표시합니다.

**검색 결과 전체 CSV 다운로드**는 현재 검색·지점 범위에 해당하는 전체 결과를 저장합니다. 화면에 보이는 한 페이지만 저장하지 않습니다. 이름·이메일·전화번호·지점·계정 연결 여부·등록일·회원권 상태·기간을 포함합니다. 암호나 결제 비밀키는 포함하지 않습니다.

CSV는 엑셀에서 열 수 있습니다. 한글 표시용 UTF-8 BOM을 포함하고 수식으로 해석될 수 있는 입력은 방어 처리합니다. 전화번호 앞자리 0을 유지하려면 엑셀 데이터 가져오기에서 전화번호 열을 텍스트로 지정하세요. 파일에는 회원 연락처가 있으므로 센터 담당자에게만 보관·공유하세요.

### 출석 조회

**출석·기기 설정** 상단에서 날짜 범위, 회원 이름, 현재 지점 또는 관리 지점 전체로 조회합니다. 30초마다 갱신되고 수동 새로고침도 가능합니다. 기존 출석, 온라인 구매 회원 출석, 직접 등록한 회원 출석을 합쳐 보여줍니다. 기존 기록에 남은 실패 사유도 표시합니다. 이번 출석 단말의 거절은 화면에 안내하고 성공 출석만 저장합니다.

출석용 기기 등록과 전화번호 뒤 4자리 확인 방식은 유지합니다. 한국시간 하루 한 번, 월요일부터 주간 횟수를 계산합니다. 여러 유효 회원권이 있으면 남은 주간 횟수가 있는 센터 부여 수강증을 우선 사용하고, 이어 구매 회원권·기존 회원권을 확인합니다. 주간 출석일 수는 회원 기준으로 합산합니다.
