# 사용 안내

## 상품에 사진 넣기
1. 관리자 화면 오른쪽 위에서 센터를 선택합니다.
2. **상품 관리 → 상품·사진 수정 → 사진 선택**을 누릅니다.
3. JPG, PNG, WebP 사진(5MB 이하)을 고르고 **상품 저장**을 누릅니다.
4. 오른쪽 위 **회원 화면**에서 상품 사진을 확인합니다.

사진은 상품 카드 비율에 맞춰 가운데를 기준으로 잘립니다. 글씨를 많이 넣은 포스터보다 가로형 상품·운동 사진이 적합합니다.

## 첫 페이지 배경 바꾸기
1. **회원 화면 꾸미기**를 누릅니다.
2. 배경색을 고르거나 **배경 이미지 → 사진 선택**을 누릅니다.
3. 첫 화면 문구와 이미지 어둡기를 조정합니다.
4. 오른쪽 모바일 미리보기를 보고 **디자인 저장**을 누릅니다.

설정은 선택한 센터에만 적용됩니다. 배경 이미지의 **삭제**를 누르면 배경색이 다시 표시됩니다.

## 가상 가입·결제·출석 확인
- 회원 화면 위의 가상 회원에서 **이서연**을 선택하거나 **등록**으로 새 테스트 회원을 만듭니다.
- 원하는 회원권 → 락카 옵션 → **테스트 결제하기** 순으로 진행합니다.
- 하단 **내 이용권**에서 구독 정보를, **입장**에서 출석 결과를 확인합니다.
- 관리자에서 상품 가격을 바꿔도 기존 가입자의 금액은 유지됩니다.
- 구독 해지 시 현재 기간은 유지됩니다. 현재 테스트 버전은 실제 재결제를 자동 실행하지 않습니다.

실제 회원 로그인과 Supabase·Toss 운영 연결은 아직 완료되지 않았습니다. 모든 이름·휴대폰·결제는 가상 정보로 테스트해 주세요.
