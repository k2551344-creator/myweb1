# 검증 기록

2026-09-29 작성.

## 통과
- TypeScript 정적 검사.
- Cloudflare Worker / 웹 클라이언트 빌드.
- 업무 규칙 테스트 12개: 월말·윤년, 가격 보존, 기간 말 해지, 실패 결제 무배정, 중복 결제, 정원·락카 초과 차단, 중복 출석, 센터·정지·만료 차단, 주간 제한, 락카 변경, 센터별 결제 모드, 일회성 재고, 입력 검증.
- 로컬 HTTP: PNG 업로드·원본 반환, 상품 사진 저장, 배경 이미지와 색상 저장, 다시 조회 시 유지, 다른 센터 불변.
- 로컬 HTTP: 위장 이미지 및 외부 출처의 저장 요청 거부.
- 브라우저: 관리자 화면·꾸미기 미리보기, 색상 입력·저장 성공, 회원 모바일 화면 전환.
- 390px 모바일 너비에서 가로 넘침 없음.
- WebMCP 화면 전환 도구 정상 입력 및 잘못된 센터 거부 확인.

## 미검증 / 제한
- Windows의 Cloudflare Workers 로컬 에뮬레이터가 네이티브 오류로 시작되지 않아, 동일 UI·업무 규칙을 쓰는 Node/Vite + SQLite 로컬 미리보기로 검증했습니다.
- Cloudflare D1/R2 운영 배포에 대한 통합 검증은 하지 못했습니다.
- 게시 준비 도중 Sites 플러그인 경로와 게시 스크립트를 더 이상 찾을 수 없어 온라인 배포는 하지 못했습니다. 사이트 등록만 된 상태이며 게시 URL은 제공하지 않습니다.
- 브라우저 파일 선택은 키보드 Enter 방식으로 확인했습니다. 이미지 업로드·저장·연결 해제까지 정상 동작했습니다.
- Supabase 스키마는 로컬 PostgreSQL(PGlite)에서 40개 설치·RLS·제약 테스트를 통과했습니다. 실제 사용자 Supabase 서비스와의 통합은 미검증입니다. supabase/setup/검증결과.json 참고.
- 실제 Supabase 회원 인증, PG 정기결제, 재결제 스케줄 및 QR 생성은 미구현입니다.

## 재현
- 업무 규칙: `node scripts/test-domain.mjs`
- 정적 검사: `node node_modules/typescript/bin/tsc --noEmit`
- 빌드: `node scripts/run-framework.mjs build`
- Windows 로컬 실행: `node scripts/local-preview.mjs`
- 실행 중 이미지·저장 테스트: `node tests/http.mjs` (테스트 PNG는 `.sites-runtime/upload-test.png`)
